# For Miss Nurse

A static bouquet website for GitHub Pages. The tulips animate in the browser and the envelope opens the letter. Reduced-motion settings show the finished bouquet immediately.

## Edit the letter

Edit the `letter` value in `messages.json`. Use `\n\n` between paragraphs. Run `python generate.py`, then commit and push `messages.json` and the generated `index.html`. The appreciation field is retained for future use but is not displayed.

## Publish

In GitHub, open **Settings → Pages**, select **Deploy from a branch**, then choose **main** and **/(root)**. GitHub Pages automatically redeploys after changes are pushed. Open the URL shown on the Pages settings screen.

The bouquet artwork and its timing are generated by `generate.py`; the animation runs in the browser and does not require Python on the visitor's device. `draw_garden.py` and its SVG are retained from the earlier Python Turtle experiment.
